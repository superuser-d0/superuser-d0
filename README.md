## Projects

### [Archlence](https://github.com/superuser-d0/archlence) — desktop

Local-first personal finance and portfolio management. Accounts, transactions,
budgets, subscriptions, debts, credit cards and investments in one workspace.
The data stays on the machine, and sensitive fields are encrypted.

`Python` · `Kivy / KivyMD` · `SQLite` · `Windows / Linux` · `Apache-2.0`

### [Archlence Mobile](https://github.com/superuser-d0/archlence-mobile) — Android

The Flutter client for Archlence: the same workspace on a phone, with the data
never leaving the device. Fields are encrypted with AES-256-GCM under a key held
in the Android Keystore. No account to create, no server to talk to. Turkish and
English interfaces, both complete.

`Dart` · `Flutter` · `drift / SQLite` · `AES-256-GCM` · `Apache-2.0`

### [ZapretTR](https://github.com/superuser-d0/zapret-tr) — Windows

A front-end for [zapret](https://github.com/bol-van/zapret)'s `winws` engine that
searches for anti-DPI parameters that work on a given connection, rather than
asking you to paste a command line you cannot evaluate. Each candidate is
measured against real connections, and one is only marked `verified` after it
passes 3/3 across independent runs.

`C#` · `.NET 8` · `WPF` · `Inno Setup` · `MIT`
