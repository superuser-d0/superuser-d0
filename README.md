### [Archlence Mobile](https://github.com/superuser-d0/archlence-mobile) — Android

The **Flutter client for Archlence**: the same personal finance workspace on a phone, with the data never leaving the device.

Accounts, cards, transactions, holdings, a budget and savings goals are stored locally and encrypted field by field with AES-256-GCM, under a key held in the Android Keystore. There is no account to create and no server to talk to.

The project focuses on:

* verifiable privacy — every outbound URL lives in one file, and price lookups carry symbols, never balances;
* parity with the desktop app, tested against fixtures generated by the desktop's own modules;
* a backup format readable in both directions, restored under a journal that survives the process being killed;
* Turkish and English interfaces, both complete;
* running the app on real hardware, because screen defects are invisible in the source.

## How I Work

Both of my projects are the same argument made twice: a claim is worth as much
as the way you can check it.

```text
Fixtures generated by the source of truth, not written by hand
Tests that are deliberately broken to prove they can fail
Limitations documented in the open, including the self-inflicted ones
The app run on real hardware, because reading it is not the same as using it
```
